## Overview

Etiqueta compacta para representar **estado**, **categoría** o **conteo**.
Es visual, no interactiva — si necesitás que algo sea clicable, usá
`Button variant="soft"` en su lugar.

Combina **`variant`** (forma) con **`color`** (tono semántico) para dar
**3 × 8 = 24 combinaciones** sincronizadas con Figma
_"Design Tokens — Tailwind Sync"_.

Construido sobre `@base-ui/react/use-render` — soporta `render` para
montar como `<a>`, `<button>`, etc. preservando accesibilidad.

## Cuándo usar

- **Estado de un registro** → `variant="soft"` con color semántico (Publicado, Rechazado, Pendiente, Borrador…).
- **Categoría o taxonomía** → `variant="outline"` (Front-end, Backend, Diseño…).
- **Conteo o tag numérico** → `variant="fill"` con número.
- **Etiqueta de versión** → `variant="soft" color="muted"` (`v1.2.0`, `beta`, `internal`).
- **Como enlace de filtro** → `render={<a href="?status=draft" />}`.

## Cuándo **no** usar

- **Botones interactivos** → usá `<Button>`. El Badge no debería ser el target de un click.
- **Notificaciones dismissibles** → usá un componente de Toast/Alert.
- **Texto largo** → el badge es para **1–3 palabras**. Si necesitás más, es un párrafo.

---

## Anatomía

```
[ Ícono opcional ] [ Texto · 0.625rem · uppercase · tracking-widest ] [ Ícono opcional ]
```

- Padding fijo: `px-2 py-0.5`.
- Tipografía: **Label/Small** (Inter Semi Bold, 10px, letter-spacing 2px) — la misma que usa Figma.
- `rounded-none` por defecto; agregá `rounded-full` vía `className` si necesitás una píldora.

## Accesibilidad

- **Semántica por defecto**: `<span>` — no tiene rol interactivo. Si el contenido es accionable, agregá `render={<a/>}` o `render={<button/>}`.
- **Color no es suficiente**: el badge transmite estado **también con texto**. Ej. `<Badge color="success">Activo</Badge>`, no solo un punto verde.
- **Contraste**: `fill` y `soft` con `color="muted"` tienen contraste bajo por diseño (≤1.2:1 vs fondo). Reservá muted para casos donde el texto ya se explique solo.
- **Íconos**: si el ícono carga significado (✓ / ✗ / !), pasá `aria-hidden="true"` al `<span data-icon>` y dejá que el texto comunique el estado.

---

## Decisiones de diseño

- **Sin variantes `ghost` ni `link`** — el Badge es visual, no interactivo. Si necesitás esos comportamientos, usá Button.
- **`badgeVariants`** exportado para extender componentes no-Badge (ej. un `<Tag>` que herede estilo).
